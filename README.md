# 환상수호전 IV 한국어 패치 (Suikoden IV Korean Patch)

![환상수호전 IV 한국어 패치 타이틀 화면](images/title.png)

PS2 일본판 幻想水滸伝IV (Genso Suikoden IV)용 비공식 한국어 번역 패치입니다.
게임 ISO는 배포하지 않으며, 본인이 가진 원본 ISO에 적용하는 xdelta 차분 패치만 제공합니다.

> ⚠️ **패치는 반드시 아무것도 적용하지 않은 원본 ISO에 적용하세요.**
> 이전 버전 패치를 적용한 ISO에는 적용되지 않습니다. 이미 한글 패치를 쓰고 계셨다면,
> 보관해 둔 원본 ISO를 다시 꺼내 새 패치를 적용해 주세요.

> **v0.5.0은 처음부터 엔딩까지 한 번 플레이하며 확인한 버전입니다.** 번역·표시 검수는 계속 진행 중이며,
> 오역, 어색한 문구, 칸을 넘는 UI 등이 남아 있을 수 있습니다.

## 적용 방법

### xdelta UI / Delta Patcher (Windows)
1. `Suikoden4_KR_v0.5.0.xdelta`를 받습니다.
2. xdelta UI 또는 Delta Patcher에서 **Patch**에 xdelta 파일, **Source**에 원본 ISO를 지정합니다.
3. 결과 파일 이름을 정하고 적용합니다.

### xdelta3 명령줄
```
xdelta3 -d -s 원본.iso Suikoden4_KR_v0.5.0.xdelta 결과.iso
```

## 현재 상태 (v0.5.0)

- 대사·선택지·메뉴·아이템·팝업·지역명 등 게임 내 텍스트를 한국어로 표시합니다.
- 처음부터 엔딩까지 한 번 플레이하며 표시와 진행을 확인했습니다.
- 한글 표시를 위해 게임 실행 파일과 글꼴·UI 코드 일부를 수정했습니다.
- 확인 환경: PCSX2 에뮬레이터. 실기(PS2)에서는 확인하지 않았습니다.

### 알려진 문제
- 긴 로딩 중 NOW LOADING 애니메이션에 가끔 깨진 프레임이 스칠 수 있습니다. 원판에서도 나타나는 현상입니다.

문제를 발견하면 Issues에 스크린샷과 함께 알려 주세요.

## 변경 이력

### v0.5.0 (2026-09-24)
- 처음부터 엔딩까지 한 번 플레이하며 확인했습니다. 그 과정에서 발견한 문제와 번역 검수 결과를 반영했습니다. 플레이 중이시라면 이 버전으로 업데이트하시길 권합니다.
- 아이템·무기·기술·적 이름과 설명을 전체적으로 다시 검수해 표기를 정리했습니다.
- 인물별 말투와 호칭을 원문에 맞게 다듬었습니다.
- 기술 설명 일부가 칸을 넘어 잘리던 문제를 고쳤습니다.
- 사운드 테스트의 곡 이름이 표시되지 않거나 깨지던 문제를 고쳤습니다.
- 팽이 게임 결과 창과 전쟁 미니게임의 미번역·깨짐·칸 넘침을 고쳤습니다. 전쟁 미니게임의 장 제목 그림도 한국어로 바꿨습니다.
- 전투 명령과 문장 조각 화면의 표기를 다듬었습니다.
- 원문과 뜻이 다르게 옮겨졌던 대사를 정정했습니다.
- 지역명 검수를 마치고 표기를 확정했습니다.
- 패치는 원본 ISO에 적용합니다. 이전 버전을 적용한 ISO에는 적용할 수 없습니다.

- 미니게임과 일부 메뉴에서 한글이 깨져 보이던 부분을 고쳤습니다.
- 배·본거지·군단 이름을 지을 때 한글 자판이 제대로 나오지 않던 문제를 고쳤습니다.
- 가게, 전투, 해전 화면에 일본어로 남아 있던 문구를 번역했습니다. 적 기술 이름과 합동 공격 이름도 함께 정리했습니다.
- 원문과 뜻이 다르게 옮겨졌던 대사와 숫자 표기를 정정했습니다.
- 메뉴 항목이 칸 안에서 어긋나 보이던 부분과 지역명 표기를 다듬었습니다.
- 배와 군단의 기본 이름이 일본어로 표시되던 문제를 고쳤습니다. 이전 버전에서 만든 세이브에도 적용됩니다.
- 이야기책 「장미의 검사」의 번역되지 않았던 화를 번역했습니다.
- 패치는 원본 ISO에 적용합니다. 이전 버전을 적용한 ISO에는 적용할 수 없습니다.
